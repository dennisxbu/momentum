# Dokumentation

Dieses Verzeichnis ist das Projektgedächtnis. Vorhandene Dateien fortführen, keine parallelen Status- oder Entscheidungssysteme anlegen.

| Datei | Zweck |
| --- | --- |
| [status.md](status.md) | Aktueller Schritt, vorhandene Funktionen, offene Grenzen, nächste Entscheidung, Umfang Version 1, Abnahme |
| [entscheidungen.md](entscheidungen.md) | Entscheidungen mit Status, Begründung und Grundlage |
| [nutzungskonzept.md](nutzungskonzept.md) | Schritt 1: Tagesablauf, Prüfszenarien, Prinzipien als Vorschlag |
| [umfang-v1.md](umfang-v1.md) | Schritt 2: vorgeschlagener Umfang von Version 1 (Arbeitsgrundlage für Schritt 3) |
| [bedienkonzepte.md](bedienkonzepte.md) | Schritt 3: Vergleich und Empfehlung der Bedienkonzepte |
| [bedienkonzepte/](bedienkonzepte/) | Wegwerfbarer visueller Entwurf, kein produktiver Stack |
| [entwicklung.md](entwicklung.md) | Git/GitHub, Geheimnisse, was nicht ins Repo gehört |
| [context/](context/) | Vision, Originalquellen, Schritt-Prompts |

App-Code, Framework und produktive Daten gehören nicht hierher, solange der beauftragte Schritt das nicht vorsieht.
